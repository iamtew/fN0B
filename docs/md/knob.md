# The knob

There is exactly one knob. What it does depends on the preset you have loaded, and the line under the knob tells you what is moving right now.

- Turn it up to move through the preset's character.
- Double-click to return it to 0%.
- The percentage box under the knob shows where you are.

Because the knob drives several parameters at once, the safest way to learn a preset is to sweep it slowly from one end to the other and listen. Nothing you can do with one knob will produce a bad sound; the mapping is built so every position is musical.

The vertical sliders are not a second knob. Left is input gain, right is output gain, both ±12 dB with 0 dB in the middle. Type in the box if you want a number. The same strip is a meter: it shows the signal after that trim.

## Why one knob

Most plugins ask you to choose between a hundred parameters and hope. fN0B makes the choice for you: someone already picked the three or four that matter for this effect and wired them to a single sweep. You get the fun part, which is listening, without the part where you second-guess a high shelf.
